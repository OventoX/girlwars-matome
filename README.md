# 少女ウォーズ キャラクターまとめ表（データベース ＆ 部隊編成シミュレータ）

ゲーム『少女ウォーズ：幻想天下統一戦』のキャラクター一覧、スキル・奥義・パッシブ・超進化詳細、部隊編成シミュレータ、およびTier評価を網羅した統合Webアプリケーションです。

城プロREツール（ShiroProMatome）と同系統のアーキテクチャを採用し、Webサーバー不要で**ローカルの `app/index.html` を開くだけで100%完全オフライン動作**します。また、GitHub Pages にそのまま静的デプロイ可能です。PWA（Progressive Web App）にも完全対応しています。

---

## 🌟 主な機能

### 1. キャラクター一覧（カードギャラリー / まとめ表テーブル / 大画像ビュー）
- **高画質イラスト中心のカードUI**:
  - 各キャラクターの公式立ち絵・スチル（全151体）を大きく表示。
  - レアリティ（UR閃39体・UR33体・SSR55体・花嫁24体）、タイプ（力・智・猛）、系統（風・花・雪・月）のカラーバッジ。
  - **情報の鮮度バッジ**: 「🟢 最新」「🔵 2025.XX」「⚠️ '24情報」を更新日からの経過日数でデータ連動自動判定。
- **クイックアクション**:
  - カード上の「☆ お気に入り登録（★）」ボタン（LocalStorageで自動永続化、無効IDの自動掃除機能付き）。
  - 「＋編成」ボタンで、1クリックで部隊編成スロットへ追加。
- **インクリメンタル検索 & 複合フィルター**:
  - キャラ名（漢字・ひらがな）、声優名（CV）、ロール（定位）でリアルタイム検索。
  - レアリティ・タイプ・系統・鮮度・お気に入りのみによる多角的な絞り込み。
  - 五十音順・レアリティ順・情報更新日順のソート対応。

### 2. ⚔️ 部隊編成シミュレータ（新機能！）
- **少女ウォーズの戦闘陣形を完全再現**:
  - **先発出陣陣形（6名）**: 前列3名（盾・先鋒・サポート）＋ 後列3名（火力・主力）。
  - **後発陣（控え・6名）**: 戦闘不能時に出撃する控え6名（計12名編成）。
- **リアルタイム・シナジー分析**:
  - 先発6名の**職業・タイプ比率（力将 / 智将 / 猛将）**を自動集計。
  - 先発6名の**系統属性比率（風 / 花 / 雪 / 月）**をリアルタイム算出。
- **可逆テキスト入出力（クリップボード共有）**:
  - 「📋 編成テキストをコピー」で、SNSや攻略メモに貼り付け可能なテキストを一括書き出し。
  - 「📥 テキストから反映」で、テキストを貼り付けるだけで部隊を瞬時に復元。

### 3. キャラクター詳細モーダル
- **大画面イラスト & 出典クレジット**:
  - 公式立ち絵を大きく表示。画像の一次情報出典元へのリンクを明記。
- **スキル・奥義の全文表示（UR閃39体＋UR33体の計72体収録）**:
  - 通常スキル、パッシブスキル、奥義、超進化（火炎Lv1〜3 / 氷魂Lv1〜2）の効果テキスト全文および用語解説（ブロック烙印など）を表示。
  - ※wiki等でスキルテキストが存在しない古いキャラは、捏造を防止するため「スキル詳細未記載」と明示。
- **評価メモ & おすすめ宝石**:
  - 最新の環境における強み・特徴の解説要約。
  - マトメバコ！調べによる「おすすめ宝石」の推奨セットを表示。
- **セリフ集 & プロフィール**:
  - wikiに収録された召喚時・タップ時・MVP時などのセリフや背景ストーリーを閲覧可能。
- **鮮度・出典警告**:
  - 2024年の古いデータには「※2024年8月時点の情報です」の注意文を表示。

### 4. Tier表・評価ランキング
- **2024年 wiki Tier表**:
  - 少女ウォーズ@wikiのPVPランキング（T0〜T3・29キャラ）の寸評とアイコンを完全再現。クリックで各キャラの詳細モーダルへ直接ジャンプ。
- **2026年 UR閃キャラ強み一覧**:
  - 最新環境（2026年11月時点）における全39体のUR閃キャラの強み・役割を五十音順で一覧表示。

## 🚀 使い方

### ローカルでの起動
Node.js や Python 等のサーバー起動は不要です。
ブラウザ（Google Chrome, Edge 等）で以下を開くだけで動作します。

```
app/index.html
```

### GitHub Pages での公開
本リポジトリは GitHub Pages に最適化されています。
リポジトリの **Settings > Pages** にて：
- **Source**: `Deploy from a branch`
- **Branch**: `main` / `/(root)`

を選択して保存すると、ルートの `index.html` から自動的に `app/` へリダイレクトされ、世界中からアクセス可能になります。
公開URL: `https://<ユーザー名>.github.io/girlwars-matome/`

## 🔄 データ更新手順

新キャラクターが追加された際は、以下のコマンドを実行するだけで最新データを取得・再生成できます。

```powershell
python -X utf8 tools/build_data.py
git add .
git commit -m "update: キャラデータ更新"
git push origin main
```
