# 少女ウォーズ キャラクターまとめ表（データベース ＆ 部隊編成シミュレータ）

ゲーム『少女ウォーズ：幻想天下統一戦』のキャラクター一覧、スキル・奥義・パッシブ・超進化詳細、部隊編成シミュレータ、およびTier評価を網羅した統合Webアプリケーションです。

城プロREツール（ShiroProMatome）と同系統のアーキテクチャを採用し、Webサーバー不要で**ローカルの `app/index.html` を開くだけで100%完全オフライン動作**します。また、GitHub Pages にそのまま静的デプロイ可能です。PWA（Progressive Web App）にも完全対応しています。

---

## 🌟 主な機能

### 1. キャラクター一覧（カードギャラリー / まとめ表テーブル / 大画像ビュー）
- **高画質イラスト中心のカードUI**:
  - 各キャラクターの公式立ち絵・スチル（全215体）を大きく表示。
  - レアリティ（UR閃39体・UR33体・SSR54体・花嫁89体）、タイプ（力・智・猛）、系統（風・花・雪・月）のカラーバッジ。
  - **情報の鮮度バッジ**: 「🟢 最新」「🔵 2025.XX」「⚠️ '24情報」を更新日からの経過日数でデータ連動自動判定。
- **クイックアクション**:
  - カード上の「☆ お気に入り登録（★）」ボタン（LocalStorageで自動永続化、無効IDの自動掃除機能付き）。
  - 「＋編成」ボタンで、1クリックで部隊編成スロットへ追加。
- **インクリメンタル検索 & 複合フィルター**:
  - キャラ名（漢字・ひらがな）、声優名（CV）、ロール（定位）でリアルタイム検索。
  - レアリティ・タイプ・系統・鮮度・お気に入りのみによる多角的な絞り込み。
  - 五十音順・レアリティ順・情報更新日順のソート対応。

### 2. ⚖️ キャラクター比較ビュー（新機能！）
- **最大4体の横並び比較**:
  - キャラ一覧や詳細モーダルから「⚖️」ボタンで最大4体を選択し、属性・ステータス・スキル要点を一括比較。
  - レアリティ、タイプ（力/智/猛）、属性系統（風/花/雪/月）、初期レアリティ、スキル本文の有無、通常/奥義スキル要点、超進化（火炎/氷魂）段階、効果タグ、評価サマリー、出典と鮮度を並列表示。
- **優劣ハイライト**:
  - レアリティの最高位（★ 最高位）や超進化段階数の最多などを客観的基準でハイライト。比べる材料のない項目は捏造せず「未取得/未設定」と明示。
- **ワンクリック・プリセット**:
  - 「UR閃主力アタッカー比較」「PVPサポーター比較」ボタンにより、すぐに実戦的な比較を体験可能。

### 3. 🏷️ スキル効果タグ ＆ 公開求人式 逆引きAND検索（新機能！）
- **14種類の効果タグ自動抽出**:
  - 全体攻撃、行動不能付与、戦意回復、戦意減少、復活/死亡回避、自己回復、味方回復、被ダメ分配、デバフ付与、デバフ解除/免疫、追撃/反撃、追撃阻止、防御無視/貫通、バフ付与。
  - スキル本文由来（🗡️）と評価サマリー由来（📝）を視覚的に区別。
- **公開求人スタイル AND絞り込み**:
  - 複数のタグを同時に選択し、「選択した全てのタグを満たすキャラクター」のみを瞬時に抽出可能。

### 4. 📊 複数ソース評価の併記 ＆ 評価変更履歴（新機能！）
- **3系統の評価ソースを独立併記**:
  - 🏛️ 少女ウォーズ@wiki（2024年PVP Tier表 & 寸評）
  - 📖 へたれリムルの攻略ブログ（2026年最新環境におけるUR閃の強み・役割解説）
  - 💎 マトメバコ！（2026年おすすめ宝石編成）
- **環境評価バッジ**:
  - 複数ソースで評価が記載されているキャラに「🔀 複数評価」、2024年wikiのみのキャラに「⚠️ '24評価のみ」バッジを付与。
- **Tier・評価変更履歴タイムライン**:
  - 過去のwiki評価から最新のUR閃昇格・ブログ評価への変遷を日付・理由・出典URL付きでタイムライン表示。

### 5. ⚔️ 部隊編成シミュレータ（共有URL ＆ 1枠差し替え比較）
- **少女ウォーズの戦闘陣形を完全再現**:
  - **先発出陣陣形（6名）**: 前列3名（盾・先鋒・サポート）＋ 後列3名（火力・主力）。
  - **後発陣（控え・6名）**: 戦闘不能時に出撃する控え6名（計12名編成）。
- **🔗 編成の共有URL**:
  - URLパラメータ（`?party=...`）に編成をエンコードし、開くだけで同じ部隊を完全再現。
- **💾 編成セット管理（複数保存・切替）**:
  - 名前を付けて部隊編成を複数保存し、ドロップダウンからワンクリックで呼び出し・切替・削除可能。
- **🔄 1枠差し替え比較シミュレータ**:
  - 特定のスロット（枠1〜12）を別のキャラに差し替えた場合の、先発タイプ比率・系統比率の変化、および「スキル効果タグの増減差分（＋追加 / −喪失）」を客観的データのみでリアルタイム算出（※捏造数値・推測戦闘力は一切出力しません）。
- **リアルタイム・シナジー分析**:
  - 先発6名の**職業・タイプ比率（力将 / 智将 / 猛将）**を自動集計。
  - 先発6名の**系統属性比率（風 / 花 / 雪 / 月）**をリアルタイム算出。
- **可逆テキスト入出力（クリップボード共有）**:
  - 「📋 編成テキストをコピー」でSNSや攻略メモに貼り付け可能なテキストを一括書き出し。
  - 「📥 テキストから反映」で、テキストから部隊を瞬時に復元。

## 🚀 使い方

### ローカルでの起動
Node.js や Python 等のサーバー起動は不要です。
ブラウザ（Google Chrome, Edge 等）で以下を開くだけで動作します。

```
app/index.html
```

### GitHub Pages での公開
本リポジトリは GitHub Pages に最適化されています。
リポジトリの **Settings > Pages** にて：
- **Source**: `Deploy from a branch`
- **Branch**: `main` / `/(root)`

を選択して保存すると、ルートの `index.html` から自動的に `app/` へリダイレクトされ、世界中からアクセス可能になります。
公開URL: `https://<ユーザー名>.github.io/girlwars-matome/`

## 🔄 データ更新手順

新キャラクターが追加された際は、以下のコマンドを実行するだけで最新データを取得・再生成できます。

```powershell
python -X utf8 tools/build_data.py
git add .
git commit -m "update: キャラデータ更新"
git push origin main
```
